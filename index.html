🌱 First Steps

What is an AI Skill?

An AI skill is a small instruction file (SKILL.md) that you give to an AI assistant like Claude or Cursor. Instead of writing the same long prompt every time, you save it once and reuse it with a single command.

Think of it like a custom research assistant who already knows your workflow — just tell it what to do and it follows your exact method.

Quick Start

Get up and running in under 2 minutes

1

Install Your AI Tool

Choose your preferred AI coding assistant:

🤖 Claude Code ⌨️ Cursor ✨ Gemini CLI
2

Copy a Skill

Clone a skill to your tool's skills directory:

# For Claude Code mkdir -p ~/.claude/skills git clone https://github.com/meleantonio/awesome-econ-ai-stuff ~/.claude/skills/econ-ai
3

Use the Skill

Invoke via slash command or natural language:

/r-econometrics Run a DiD analysis on treatment_data.csv

No install needed to try your first skill. Use Claude.ai directly in your browser:

1

Open Claude in your browser

Go to claude.ai and sign in for free. No credit card required.

2

Open the Research Ideation skill

Click the skill below and copy the instructions from the page.

View Research Ideation Skill →
3

Paste and describe your topic

Paste the instructions into Claude, then describe your research area. Watch it generate structured research questions.
